Each room is a separate project file, but they all use the same character set and tile painting scheme.

Each room is 22 x 40 characters. This is since the top two rows are used for the HUD, and the bottom line is a status line. The game map is 22 lines in betwwen.

You need to export each map as a ASM file to use it in the game. For room 1, export all (colours, charset, map). For other rooms just export map.
