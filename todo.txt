Major refactor: world data is now generated from a config file. titan.yaml
defines rooms (bounds, player start, vchar64 map, map-view box), robots
(type, start, patrol waypoints), hidden items (label, found-text, position),
doors (rectangle, destination, arrival position, optional key item), lasers
and terminal zones, plus the start clock and death penalty.
tools/genworld.py validates it and generates src/world.asm (data tables +
room maps + runtime state arrays) as part of make. Game code is fully
table-driven: generic actor patrol AI, door/laser/bounds checks, item
search/inventory, sprite slot assignment per room. Adding rooms/robots/
items/doors/lasers needs no code changes (except sector-map art in map.asm
and, for a new robot type, its sprite data).

Fixed along the way: terminal/search are human-mode only (space no longer
re-opens the terminal while driving a robot); popups now stay until a fresh
space press (the opening keypress used to close them instantly via the
KERNAL buffer); locked-door popup border alignment; the laser now also kills
when approached from the right.
